## Instalación en WPCode (jetcab.mx)
7. WP Admin → Code Snippets → Add Snippet → "Add Your Custom Code (New Snippet)" → tipo **PHP Snippet**.
8. Pegar el contenido completo de cada archivo **sin** la línea `<?php` inicial (WPCode la agrega). Un snippet por archivo; nombres sugeridos: "Rutas Domésticas ES (PHP)", "Landing Confidencialidad (PHP)", "Landings Tipos de Jet (PHP)".
9. Insert Method: **Auto Insert** · Location: **Run Everywhere** · Priority: 10 · Activar el toggle y Guardar.
10. WPCode NO es accesible vía REST (`/wp-json/wpcode/v1/*` → 404, ver skill `jetcab-wordpress-rest-api`) y el login admin está bloqueado por Cloudflare: los snippets debe pegarlos el cliente o quien tenga sesión de admin. Plan B sin WPCode: publicar cada página como standalone vía REST API con esa misma skill (perdiendo las rewrite rules, pero manteniendo el HTML, JSON-LD y canonicals).
11. **Obligatorio:** Ajustes → Enlaces permanentes → Guardar cambios (sin modificar nada) para refrescar las rewrite rules; sin este paso las URLs devuelven 404.
12. Probar: `curl -sI https://jetcab.mx/vuelos-privados-a-cancun/ | head -1` debe dar `200`; repetir para `/vuelos-privados-confidenciales/`, `/light-jets-toluca/` y `/long-range-jets-toluca/`.
